Investigações arquivadas.

Nem todo mistério termina com uma resposta definitiva. Aqui ficam os casos já investigados, com o que as evidências permitem afirmar — e o que continua em aberto.

CASE FILE / 001 · MANUSCRITOS

O Manuscrito Voynich

Um códice ilustrado do século XV reúne uma escrita ainda não decifrada de forma consensual. Não existe uma tradução comprovada; hipóteses continuam em debate.

CASE FILE / 002 · ARQUEOLOGIA

O mecanismo de Anticítera

Recuperado de um naufrágio grego, o mecanismo de bronze usava engrenagens para representar ciclos astronômicos. Pesquisadores ainda investigam seus detalhes.

CASE FILE / 003 · ASTRONOMIA

O sinal Wow!

Detectado em 1977, o sinal de rádio chamou atenção por suas características, mas não foi confirmado novamente. Sua origem permanece desconhecida.

CASE FILE / 004 · HISTÓRIA MARÍTIMA

O caso do Mary Celeste

Encontrado abandonado no Atlântico em 1872, o navio deu origem a muitas versões populares. Nenhuma explicação definitiva para o abandono foi estabelecida.

# Nexora

An independent editorial project about practical technology, useful digital tools, and better workflows.

## Local preview

From this directory:

```bash
python -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173` on the same computer.

## Current build

- Responsive editorial homepage with a premium dark visual identity.
- Four original English-language guides.
- About and draft Privacy pages.
- Basic `robots.txt` allowing crawler access.
- No analytics, advertising, newsletter collection, user accounts, or tracking scripts.
- Local preview currently served on port `4173`.

## Before public launch

1. Choose and verify a domain or hosting subdomain; the Nexora name is still provisional.
2. Add the final canonical URLs, Open Graph metadata, and a sitemap using the real domain.
3. Establish a real contact method and replace the draft privacy policy with one matching the actual host and enabled services.
4. Fact-check every product, pricing, and platform claim; add primary sources where relevant.
5. Test mobile layout, accessibility, performance, and all internal links.
6. Publish, set up Google Search Console, and submit the sitemap.
7. Consider advertising only after the publication has enough substantial original content and a responsible adult is ready to own any required AdSense account.

## Editorial standard

Prioritize practical, specific guidance over generic search-engine filler. Clearly distinguish editorial content from advertising or affiliate links. Update articles when product details or policies change.
